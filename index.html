FREE / ON-DEMAND PROCESSING

Run STEM free in Google Colab

Use the button to open the STEM notebook in Google Colab. Start the free processing session there, then return to this website to upload your song and receive the stems here.

  1. Open the notebook with the button below and sign in to Google if asked.
  2. Start the runtime: choose Runtime → Run all, then approve any Google prompts and wait for the secure tunnel URL and session token to appear.
  3. Return to this website, paste the URL and token into the connection fields, press Connect, then upload your song.

Keep the Colab tab open while processing. The session URL and token change after a restart. Google controls free GPU availability and session limits.
